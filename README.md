# IBM Data Science Capstone: SpaceX Landing Prediction

IBM Data Science capstone project applying classification models to predict SpaceX Falcon 9 first-stage landing success.

## Objective

This project is organized as a portfolio case study to show the full analysis workflow: understanding the business problem, preparing the data, exploring patterns, building the final output, and communicating insights clearly.

## Business Questions

- Which features influence Falcon 9 landing success?
- How can classification models support launch outcome prediction?
- What insights can be communicated from the full capstone workflow?
